Home

Overview

#home

UniFi Toolkit is an experimental Home Assistant app that packages the open-source UniFi Toolkit by Crosstalk Solutions (MIT). The upstream release is pinned and not modified; Ingress support is a small wrapper in this app.

#Included tools

  • Dashboard — gateway, WAN, clients and network health at a glance
  • Wi-Fi Stalker — track devices, roaming history, block/unblock
  • Threat Watch — IDS/IPS events with ignore rules and webhooks
  • Network Pulse — live network and access point charts
  • House Arrest — per-device and per-network lockdown via the UniFi zone-based firewall
Unofficial and not affiliated with Ubiquiti Inc. or Crosstalk Solutions. Report packaging problems in pol4rfuchs/ha-apps, problems in the Toolkit itself upstream.

Installation

Install & First Setup

#installation
  1. Open Settings → Apps → App Store and add the repository:
https://github.com/pol4rfuchs/ha-apps
  1. Reload the store, open UniFi Toolkit, click Install and start it.
  2. Turn on the Watchdog switch so Home Assistant restarts the app if the Toolkit process crashes.
  3. Open the UniFi Toolkit panel in the sidebar, open the configuration dialog in the Toolkit UI and enter the controller URL (e.g. https://<your-controller>) and a UniFi API key.
Controller URL and API key are not app options, because upstream only reads them from its own UI. They are stored encrypted (Fernet) in the app database.

#First start

On a fresh database upstream logs a migration warning (no such table) before it creates the schema. That is upstream behaviour and harmless.

Security

Security & Privacy

#security
  • Only the Home Assistant Ingress gateway can connect; other peers get HTTP 403. No host port is published.
  • Authentication is provided by Home Assistant. The Toolkit's own login is disabled.
  • House Arrest can create and delete firewall rules, and Wi-Fi Stalker can block clients. The Toolkit has no read-only mode, so limit the permissions of the API key you give it accordingly.
  • The panel makes no external requests: Alpine.js and Chart.js are bundled at build time (checksum verified), Google Fonts are removed and upstream's GitHub update check is answered locally. Updates arrive through Home Assistant, not the Toolkit UI.
  • Python dependencies are pinned via constraints.txt for reproducible builds.
  • The advertisement banner for the author's consulting service at the bottom of the dashboard is not shown in this app (the “Get Help” button in the header and its page stay).
  • Links to GitHub, Ko-fi and the author's website inside the Toolkit UI are ordinary links: they open only when you click them, the app itself never calls them.

#Local and external access

Local (LAN): open UniFi Toolkit in the Home Assistant sidebar. The app has no host port and is only reachable through Ingress, so the Home Assistant login protects it.

External (internet): VPN only. The Toolkit manages your network, so anyone who gets into your Home Assistant can use it. There is no port to forward; do not reach Home Assistant from the internet without two-factor authentication.

Data

Data & Backups

#data

Everything lives in /data: the SQLite database and encryption.key. Both are part of Home Assistant backups (backup: cold: the app is stopped briefly so the database is consistent) and must be restored together.

If the key is lost, saved UniFi credentials cannot be decrypted and must be entered again in the Toolkit UI.
